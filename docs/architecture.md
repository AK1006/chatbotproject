# Architecture Overview

The AI Chatbot is built on a straightforward yet effective NLP and Deep Learning pipeline.

## Core Components

1. **`intents.json` (Data Layer)**
   Acts as the brain's knowledge base. It contains various tags (intents), patterns (user inputs), and responses.

2. **`trainingData.py` (Training Layer)**
   - **NLP Processing:** Uses `nltk.word_tokenize` to split sentences and `WordNetLemmatizer` to reduce words to their base forms.
   - **Data Preparation:** Creates a Bag-of-Words (BoW) array mapping words to the corpus.
   - **Model Architecture:** 
     - Input Layer: Dense (128 units, ReLU activation)
     - Dropout (0.5) to prevent overfitting
     - Hidden Layer: Dense (64 units, ReLU activation)
     - Dropout (0.5)
     - Output Layer: Dense (matches number of intents, Softmax activation)
   - **Optimization:** Stochastic Gradient Descent (SGD) with momentum and Nesterov.

3. **`main.py` (Inference & Application Layer)**
   - **`CollegeChatBot` Class:** Loads the `chatbotmodel.h5`, `words.pkl`, and `classes.pkl` generated by the training layer.
   - Processes user input exactly like the training data.
   - Predicts the intent with the highest probability.
   - Returns a randomly selected response from the matched intent block.

## Data Flow
`User Input -> Tokenize & Lemmatize -> Bag of Words -> Model Prediction -> Intent Matching -> Final Response`
